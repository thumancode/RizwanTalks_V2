# Rizwan Talks: ইউনিভার্সাল মোশন ভিডিও মেকার (GitHub Actions)

আপনি দেবেন: **অডিও + SRT (+ ইচ্ছে হলে ছবি, ব্যাকগ্রাউন্ড মিউজিক, লোগো)**।
GitHub নিজে ভিডিও (MP4) বানিয়ে দেবে। **প্রোডাক্ট, নিউজ, টেক, শিক্ষা, রিভিউ, যেকোনো বিষয়ের** জন্য।

- **৬টি রেশিও:** 9:16 (TikTok/Reels/Shorts), 4:5 ও 3:4 (Instagram/Facebook ফিড), 1:1, 4:3, 16:9 (YouTube)
- **৫টি রেজোলিউশন:** SD (540), HD (720), FHD (1080), QHD (1440), 4K (2160)
- **২৪টি থিম:** ২৪টি পৃথক আর্ট-ডিরেকশন: আলাদা রং, ব্যাকগ্রাউন্ড প্যাটার্ন, ফ্রেম, ফন্ট, চিপ-স্টাইল ও মোশন চরিত্র (প্রিভিউ: `docs/themes-preview.jpg`)
- **১৫টি সিন টাইপ:** পুরনো পারফিউম-সিনগুলো আগের মতোই, সাথে নিউজ/সংখ্যা/উক্তি/ধাপ/তুলনা
- একই অডিও ও একই টাইমলাইন থেকে পোর্ট্রেট ও ল্যান্ডস্কেপ দুটোই, প্রতিটার কম্পোজিশন আলাদা করে সাজানো
- সব গ্রাফিক্স ভেক্টর, কোনো ইমোজি নেই। hook, whoosh, pop, chime সাউন্ড কোড দিয়ে নিজে তৈরি হয় (থিম অনুযায়ী সুর বদলায়)

## একবারের সেটআপ (মোবাইল ব্রাউজারেই হবে)

আগের মতোই। **শুধু একটা `make_video.py`** (ভেতরে ডিজাইন, থিম, সাউন্ড, সিঙ্ক সব আছে)।

1. GitHub-এ একটা নতুন repository খুলুন। Public রাখলে Actions বিনা খরচে চলে।
   Private হলে মাসে ২০০০ মিনিট ফ্রি। এক ভিডিও (FHD, ১ রেশিও) আনুমানিক ১৫-২৫ মিনিট নেয়।
2. **Add file > Upload files** দিয়ে এই ফাইলগুলো আপলোড করে Commit করুন:
   - `make_video.py`
   - `config.json`
   - আপনার অডিও (`.mp3`/`.wav`) আর SRT (`.srt`, `.txt` হলেও চলবে)
   - ছবি (`.webp`/`.png`/`.jpg`), **ঐচ্ছিক**। না দিলে থিমের নিজস্ব প্রতীক বসবে।
3. **Add file > Create new file** চাপুন। নামের ঘরে হুবহু লিখুন:
   `.github/workflows/render-video.yml`
   নিচের বড় ঘরে `render-video.yml`-এর পুরো লেখা পেস্ট করে **Commit changes** দিন।

> আগের সেটআপ করা থাকলে শুধু `make_video.py`, `config.json` আর `render-video.yml` বদলে দিলেই হবে।

## ভিডিও বানানো

1. **Actions** ট্যাব > বাম পাশে **Render video** (মোবাইলে বাটন না দেখলে **Desktop site** অন করুন)।
2. **Run workflow** চাপুন, ঘরগুলো:

| ঘর | মানে |
|---|---|
| `folder` | ফাইলগুলো মূল ফোল্ডারে থাকলে `.` (ডট), নাহলে ফোল্ডারের নাম |
| `theme` | `config` = config.json-এর থিম (ডিফল্ট), `auto` = প্রতিবার আলাদা থিম (রান নম্বর ধরে ঘোরে), `all` = ২৪টাই, অথবা একটা থিমের নাম |
| `ratios` | `9x16`, `16x9`, `1x1`, `4x5`, `3x4`, `4x3`। কমা দিয়ে একাধিক (`9x16,16x9`)। শর্টকাট: `portrait`, `landscape`, `social` (9x16+4x5+1x1+16x9), `all`। `config` = config.json-এর `ratios` |
| `resolutions` | `sd`, `hd`, `fhd`, `qhd`, `4k`। কমা দিয়ে একাধিক (`hd,fhd,4k`) বা `all` (hd+fhd+4k)। `config` = config.json-এর `resolutions` |
| `quality` | `full` = পূর্ণ মান, `preview` = দ্রুত ছোট প্রিভিউ (SD) |

3. সবুজ টিক আসা পর্যন্ত অপেক্ষা করুন। **প্রতিটি (থিম × রেশিও) আলাদা মেশিনে সমান্তরালে** রেন্ডার হয়, এবং এক রেশিওর সব রেজোলিউশন একবার রেন্ডার করেই বের হয় (সময় বাঁচে)।
4. ভিডিও নামাতে: repository-র মূল পাতায় ডান পাশে **Releases** > সর্বশেষ `Video #…`। ফাইলের নাম এমন: `White_Oud_midnight_16x9_4k.mp4`
   (`নাম_থিম_রেশিও_রেজোলিউশন.mp4`)। বিকল্প: ওই রানের পাতার নিচে **Artifacts**।

**উদাহরণ:**
- শুধু রিলস/শর্টস: ratios `9x16`, resolutions `fhd`
- একই ভিডিও পোর্ট্রেট + ল্যান্ডস্কেপ: ratios `9x16,16x9`
- ফেসবুক + ইউটিউব + ইনস্টাগ্রাম + টিকটক সব একসাথে: ratios `social`, resolutions `fhd`
- ২৪ থিমে তুলনা করে বাছতে: theme `all`, ratios `9x16`, quality `preview`
- ইউটিউবের জন্য সেরা মান: ratios `16x9`, resolutions `4k`

> ৪K ও অনেকগুলো কম্বিনেশন বেশি মিনিট খরচ করে। (থিম × রেশিও) যত বেশি, তত বেশি জব। আগে `preview` দিয়ে থিম বেছে নিন, তারপর `full`।

## প্ল্যাটফর্ম অনুযায়ী কোন রেশিও

| রেশিও | মাপ (FHD) | কোথায় |
|---|---|---|
| `9x16` | 1080×1920 | TikTok, Instagram Reels/Story, Facebook Reels/Story, YouTube Shorts |
| `4x5` | 1080×1350 | Instagram ও Facebook ফিড (সবচেয়ে বেশি জায়গা পায়) |
| `3x4` | 1080×1440 | Instagram গ্রিড, Facebook |
| `1x1` | 1080×1080 | সব প্ল্যাটফর্মের স্কয়ার পোস্ট |
| `4x3` | 1440×1080 | ক্লাসিক ল্যান্ডস্কেপ |
| `16x9` | 1920×1080 | YouTube, Facebook পেইজ ভিডিও, ওয়েবসাইট |

রেজোলিউশন: `sd`=540p, `hd`=720p, `fhd`=1080p, `qhd`=1440p, `4k`=2160p (ছোট দিক ধরে; যেমন 9x16 + 4k = 2160×3840)।

## ২৪টি থিম

`config.json`-এ `"theme": "নাম"` বা workflow-এর `theme` ঘরে দিন। প্রিভিউ: `docs/themes-preview.jpg`

| নাম | রং | ব্যাকগ্রাউন্ড / ফ্রেম | কেমন বিষয়ে মানায় |
|---|---|---|---|
| `royal` | আইভরি + সোনালি (মূল ডিজাইন) | আরাবেস্ক তারা / অলংকৃত কোণা | পারফিউম, ফ্যাশন, ইসলামিক, প্রিমিয়াম |
| `midnight` | নেভি + সায়ান | টেক গ্রিড / ব্র্যাকেট | টেক, AI, গ্যাজেট, ব্যবসা |
| `emerald` | গাঢ় সবুজ + পুদিনা | কন্টুর লাইন / ডবল ফ্রেম | স্বাস্থ্য, প্রকৃতি, ফিন্যান্স |
| `sunrise` | কমলা + কোরাল | সানবার্স্ট / গোল ফ্রেম | খাবার, অফার, এনার্জি, ইভেন্ট |
| `rose` | গোলাপি + প্লাম | বোকে / সরু ফ্রেম | বিউটি, লাইফস্টাইল, গিফট |
| `ocean` | অ্যাকোয়া + টিল | ঢেউ / ফ্রেমহীন | ভ্রমণ, ক্লিন প্রোডাক্ট, শিক্ষা |
| `crimson` | কালো + লাল | তির্যক ডোরা / নিউজ বার | ব্রেকিং নিউজ, খেলা, ড্রামা |
| `neon` | বেগুনি + ম্যাজেন্টা | স্ক্যানলাইন / নিয়ন ফ্রেম | গেমিং, সঙ্গীত, ইয়ুথ |
| `mono` | সাদা + কালো | হাফটোন বিন্দু / সরল ফ্রেম | এডিটোরিয়াল, মতামত, মিনিমাল |
| `lavender` | বেগুনি + লিলাক | অরোরা / ডটেড ফ্রেম | শিক্ষা, মেন্টাল হেলথ, ক্রিয়েটিভ |
| `luxe` | কালো + সোনালি | আর্ট-ডেকো / স্টেপড ফ্রেম | জুয়েলারি, ঘড়ি, লাক্সারি |
| `sand` | টেরাকোটা + সেজ | রেইনবো আর্ক / আর্চ ফ্রেম | হ্যান্ডমেড, ফুড, বোহো, ঘরোয়া ব্র্যান্ড |

প্রতিটি থিমের আলাদা ফন্ট, চিপের ধরন (pill / glass / outline / block / tag), অ্যানিমেশনের গতি ও সাউন্ডের সুর আছে।
রং নিজের মতো বদলাতে: `"theme": {"id": "midnight", "accent": "#ff7a00"}`
(বদলানো যায়: `accent`, `accentL`, `accentD`, `accent2`, `ink`, `sub`)।

## ব্যাকগ্রাউন্ড মিউজিক ও লোগো

- `bgm.mp3` নামে ফাইল আপলোড করুন, নিজে থেকে মিশবে, কথার সময় আওয়াজ কমবে। আওয়াজ: `"bgmVolume": 0.16` (০.০৫ = খুব নিচু, ০.৩ = জোরে)।
- `logo.png` নামে আপলোড করলে নিচের ব্র্যান্ড বারে দেখাবে।

## ছবি

- ছবির ধরন নিজে বোঝা হয়: সাদা ব্যাকগ্রাউন্ডের প্রোডাক্ট ফটো (হালকা থিমে মিশে যায়; অন্ধকার থিমে স্পটলাইটের ওপর বসে), স্বচ্ছ PNG (ছায়াসহ), সাধারণ ছবি (সুন্দর কার্ড ফ্রেমে)।
  জোর করতে: `"imageMode": "blend" | "spot" | "cutout" | "card"`
- একাধিক ছবি: `"images": ["a.jpg", "b.jpg"]` দিন, আর কোনো সিনে `"image": "b.jpg"` (বা `1`) লিখলে ওই সিন থেকে ছবি ক্রসফেডে বদলাবে।
- ছবি না থাকলে বা `"noImage": true` দিলে থিমের নিজস্ব প্রতীক (emblem) বসে।

## config.json-এ যা বদলানো যায়

| ঘর | মানে |
|---|---|
| `brand` | নিচের ব্র্যান্ড নাম (চ্যানেল/পেইজ/দোকানের নাম) |
| `website` | ওয়েবসাইট লিংক। ফাঁকা রাখলে কিছু দেখাবে না |
| `presenter` | শুরুর "Rizwan Talks" লেখা |
| `welcome` | শুরুর ছোট লেখা (ডিফল্ট `Welcome to`) |
| `productName`, `productSubtitle` | `title` সিনের নাম ও উপশিরোনাম |
| `tagline` | `title` সিনের কিকার লেখা (ডিফল্ট `presents a premium creation`)। টপিক ভিডিওতে বদলে নিন, যেমন `আজকের টপিক` |
| `theme`, `ratios`, `resolutions` | ডিফল্ট থিম, রেশিও ও রেজোলিউশন (workflow-এ `config` রাখলে এগুলো ব্যবহার হয়) |
| `outputName` | আউটপুট ফাইলের নাম (ফাঁকা থাকলে `productName` থেকে) |
| `sync` | `auto` = অডিওর বিরতি দেখে ক্যাপশন মেলানো। `srt` = আপনার SRT-এর সময় যেমন আছে |
| `syncOffset` | ক্যাপশন ও সিন সূক্ষ্মভাবে আগে/পরে করতে (সেকেন্ডে)। `-0.1` = আগে, `0.1` = পরে |
| `endHold` | অডিও শেষের পর কতক্ষণ ভিডিও চলবে (ডিফল্ট ১.৪ সেকেন্ড) |
| `scenes` | সিনের তালিকা (নিচে) |

## সিন টাইপ

প্রতিটি সিনে `"start": {"text": "কথার যে অংশ থেকে সিন শুরু"}` দিন। ওই লেখা SRT/অডিওতে যেখানে আছে, সিন সেখান থেকে শুরু হবে।
তালিকার আইটেমে `"bn"` (বা `"say"`) = কথায় যে শব্দটা বলা হচ্ছে। আইটেম ঠিক ওই মুহূর্তে পর্দায় আসে। না দিলে সমান দূরত্বে আসে।
শিরোনামের নিচের উপশিরোনাম: `"bn"` (বা `"sub"`)।

| `type` | কী দেখায় | ঘর |
|---|---|---|
| `intro` | স্বাগতম + প্রেজেন্টার (প্রথম সিন) | `welcome`, `title`, `subtitle` |
| `title` | বড় নাম রিভিল | `revealAt`, `name`, `subtitle`, `tagline` |
| `traits` | চিপের তালিকা, হিরোর দুপাশে | `heading`, `bn`, `items[{label, bn}]` |
| `notes` | রঙিন ডটসহ চিপ + স্তর-আইকন | `level` (top/heart/base), `items[{label, bn, color}]` |
| `family` (`ring`) | গোল করে সাজানো আইটেম | `heading`, `items[{label, color}]` |
| `character` | বড় বড় শব্দ একটার নিচে একটা | `heading`, `items[{label}]` |
| `list` (`occasions`, `bullets`) | নম্বরসহ তালিকা | `heading`, `items[{label}]` |
| `blend` (`fusion`) | রঙিন বৃত্ত মিশে যাওয়া | `title`, `meaning`, `accords`, `meaningAt`, `accordsAt` |
| `statement` | বড় একটা বাক্য | `text` |
| `cta` | কল-টু-অ্যাকশন বাটন + ক্লিক অ্যানিমেশন | `headline`, `line`, `button` |
| **`headline`** (`news`) | নিউজ-স্টাইল শিরোনাম (শব্দ ধরে ফোটে) | `kicker`, `text`, `source` |
| **`stat`** (`number`) | গুনে গুনে বাড়া বড় সংখ্যা + রিং | `value` (`৭২%`, `১.৫ লাখ`, `$2.5B`), `label`, `sub`, `percent`, `revealAt` |
| **`quote`** | উক্তি + বক্তা | `text`, `author`, `role` |
| **`steps`** (`timeline`) | ধাপে ধাপে টাইমলাইন | `heading`, `items[{label, text}]` |
| **`compare`** (`vs`) | দুই পক্ষের তুলনা (A vs B) | `heading`, `items[{label, value, text}]` (২টা) |

সব সিন টাইপের একটা চলনসই নমুনা: `examples/all-scenes.config.json` (আপনার নিজের অডিও/SRT-এর কথার সাথে `start`/`bn` মিলিয়ে নিন)।

লেখা বাংলা বা ইংরেজি, যেকোনোটাই হতে পারে। বাংলা শিরোনাম নিজে থেকে বাংলা ফন্টে বসে (যুক্তাক্ষর না ভেঙে)।

**নতুন টপিকের জন্য সবচেয়ে সহজ উপায়:** অডিও, SRT (আর ছবি থাকলে) আমাকে দিন, আমি নতুন `config.json` বানিয়ে দেব।

## একাধিক ভিডিও / প্রোডাক্ট

নতুন ফোল্ডার বানাতে **Create new file** চেপে নামে লিখুন `product02/config.json`, ভেতরে সেই ভিডিওর config পেস্ট করুন।
তারপর ওই ফোল্ডারে **Add file > Upload files** দিয়ে অডিও, SRT, ছবি দিন। রান করার সময় `folder` ঘরে `product02` লিখুন।

## সমস্যা হলে

- **লাল ক্রস এলে**: ওই রানে ক্লিক করে **Render video** ধাপ খুলে শেষের কয়েক লাইন আমাকে পাঠান।
- **"ফোল্ডারে অডিও আর সাবটাইটেল লাগবে"**: দুটো ফাইলই ঠিক ফোল্ডারে আছে কিনা দেখুন।
- **"অজানা থিম/রেশিও/রেজোলিউশন"**: বানান মিলিয়ে নিন (উপরের তালিকা দেখুন)।
- **সিনের শুরুর জায়গা খুঁজে পাওয়া যায়নি**: `start`-এর `text` অবশ্যই SRT-এর লেখার হুবহু অংশ হতে হবে।
- **ক্যাপশন অডিওর সাথে একটু আগে-পরে লাগলে**: `"syncOffset": -0.1` (আগে) বা `0.1` (পরে)। SRT-এ নিখুঁত সময় থাকলে `"sync": "srt"`।
- সাদা ব্যাকগ্রাউন্ডের প্রোডাক্ট ছবি সবচেয়ে ভালো মেশে। ছবি ঠিকমতো না বসলে `imageMode` বদলে দেখুন।

## সিঙ্ক কীভাবে কাজ করে

- `auto` মোডে অডিওর ভলিউম দেখে প্রতিটি বিরতি (কমা, দাঁড়ি, তালিকার প্রতিটি শব্দের ফাঁক) খুঁজে বের করা হয়। তারপর দাঁড়ি লম্বা বিরতিতে আর কমা ছোট বিরতিতে বসিয়ে প্রতিটি ফ্রেজের সময় ঠিক করা হয়। তাই SRT-এর সময় আনুমানিক হলেও ক্যাপশন, সিন আর লেবেল অডিওর সাথে মিলে যায়।
- ক্যাপশন কথার ০.০৮ সেকেন্ড আগে ফুটতে শুরু করে।
- অডিওর সাথে মেলানো `…_synced.srt` ফাইলও তৈরি হয় (Releases ও Artifacts-এ)। অন্য জায়গায় সাবটাইটেল লাগলে এটাই ব্যবহার করুন।

## ডেভেলপারদের জন্য (সোর্স)

`source/render/` ফোল্ডারে আলাদা আলাদা ফাইল: `render.py` (পাইপলাইন), `align.py` (সিঙ্ক), `sfx.py` (সাউন্ড), `themes.json` (২৪ থিম, রেশিও, রেজোলিউশন), `site/` (`base.js` লেআউট ও হিরো, `decor.js` থিমের সাজ, `scenes.js` সিন, `main.js` ফ্রেম লুপ)।
পরিবর্তনের পর `python source/tools/bundle.py` চালালে `source/dist/make_video.py` তৈরি হয়, সেটা মূল `make_video.py`-র জায়গায় বসান।
নতুন থিম যোগ করতে `themes.json`-এ একটা এন্ট্রি দিলেই হয় (`order` তালিকাতেও নাম দিন, workflow-এর `theme` অপশনেও)।


## 48 ইউনিক থিম ও আলাদা BGM

Workflow-এর `theme` ইনপুটে `all` বেছে নিলে ২৪টি পুরোনো + ২৪টি নতুন থিম রেন্ডার হবে। প্রতিটি থিমে নিজস্ব রঙ, প্যাটার্ন, ফ্রেম, মোশন/টাইপোগ্রাফি রেসিপি এবং procedural instrumental BGM profile রয়েছে। BGM প্রোফাইলগুলি স্থানীয় কোডে তৈরি হয়; কোনো বাহ্যিক ডাউনলোড বা কপিরাইটেড ট্র্যাকের উপর নির্ভর করে না। সব ৪৮টি থিম একসাথে রেন্ডার করলে বেশি সময় ও GitHub Actions artifact/release storage লাগবে।
